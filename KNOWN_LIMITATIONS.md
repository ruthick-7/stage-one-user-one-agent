# Known limitations

1. **Intervention scope.** The policy deliberately chooses home pages or abstention. Push/WhatsApp/in-app generation and scheduling are not enabled. Messaging verifier tests cover selected restrictions, not a certified sending service. A real channel needs structured copy/pricing/template rendering, delivery acknowledgements, cancellation and integration tests.
2. **Local publication.** The outbox now stages pending entries and exposes only ready ones; interrupted pending pages become abstentions on reopening. Real storage errors trigger an independent fsynced abstention journal and stop further publication in that engine instance. If both primary and recovery storage fail, execution fails visibly. After a real primary-store failure, rebuild from the input replay in a fresh output directory; full timeline/cursor resume is not implemented. The two stores are on the same machine, not independent infrastructure.
3. **Withdrawal integration.** Local serving excludes revoked pages immediately and attempts a verified replacement; otherwise it uses the default page. Revocations are durable and exported. The unchanged supplied simulator does not interpret pure revocations; it can observe replacement pages. A real deployment still needs a platform adapter that applies revocations, acknowledgements and cache invalidation.
4. **Performance scope.** The process-sharded benchmark measures local cold-start bursts including queues and durable release, using a mock provider and one SQLite file per shard. It does not establish shared-database throughput, real model p95, distributed failover or capacity for ten million viewers. Call budgets count logical model/data operations, not each Python lookup or SQL statement. Replay publication timestamps mark the release request; latency observations include completion of its final commit.
5. **Mock faults.** Provider 503s/malformed JSON/unsupported claims and bounded timeouts are reproduced locally. The fixture's 45s timeout is cancelled at 20ms. Its degraded 8s store reads activate a conservative whole-window circuit rather than the exact 20% timeout distribution. Real SQLite fault regressions complement that fixture, without pretending to test a real network database.
6. **Evidence limits.** Thirty days cannot prove lifetime absence of viewing/payment. The code documents that assumption. Signup receipt approximates signup time. Subscription eligibility uses a conservative 48h freshness limit, and "recent lapse" means 30 days. Device buffering is estimated by subtracting device timestamps, which assumes their offset did not change between creation and send. Receipt and delivery cutoffs prevent later-arriving facts from rewriting commitment-time snapshots.
7. **Measurement limits.** The simulator follows triggered users only. Baseline goals are assigned before any intervention, but many randomized users lack follow-up; some lack an eligible measurable goal. They remain explicitly inconclusive in full-arm coverage. Baseline-eligible goal contrasts retain randomized arms and report worst-case missing-outcome bounds and sampling envelopes. No full-population point estimate, positive causal claim or rollout conclusion is justified. One seed's intervals omit simulator uncertainty.
8. **Unavailable goals.** G10 has no defined measurable predicate; G11's TV signal is absent. Both are excluded rather than replaced with invented outcomes.
9. **Learning and optimization.** Outcome evidence and conservative learning are stored, but no automatic policy optimizer is trained. Failed goals can be attempted again in a later instance; an explicit retry/cooldown policy remains future work. Confidence values describe heuristic evidence sufficiency, not calibrated success probabilities.
10. **Evaluator inputs.** The original data pack stays Git-ignored. Committed sample artifacts contain only the supplied synthetic world and generated outcomes. The supplied simulator fixes its practice-day date internally; an unseen replay day needs the evaluator's corresponding simulator. The project does not silently change the simulator's source or claim unseen-day validation.
